# CompPack
This program helps you avoid the hassle of reinstalling programs after a fresh Windows installation. With just a few clicks, you can select the desired programs and install them quickly. No unnecessary steps, just installation!
Эта программа поможет вам избежать проблем с переустановкой программ после новой установки Windows. Всего несколькими щелчками мыши вы сможете выбрать нужные программы и быстро установить их. Никаких лишних действий, просто установка!
